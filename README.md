## Ordnerstruktur

```text
index.html                                  # Auswahl aller Weiterbildungen
Weiterbildungen/
  KI-in-der-Schule/
    index.html                              # Bestehendes Fortbildungsportal
    Praesentation_KI-Fortbildung.html       # Originalpräsentation unverändert
  Datenschutz-Jahresbelehrung-2026/
    Praesentation_Datenschutz.html
    Handout_Datenschutz.html
```

**Bestandsschutz:** Die bestehenden KI-Arbeitsblätter, Handbücher und Vorlagen liegen vorerst weiterhin im Repository-Stammverzeichnis und werden vom KI-Fortbildungsportal über relative Links eingebunden. Die bisherigen Stammdateien bleiben als Kompatibilitätskopien erhalten.

## GitHub Pages

Unter **Settings → Pages → Build and deployment** muss **Deploy from a branch**, Branch **main**, Verzeichnis **/(root)** gewählt sein. Bei privaten Repositories hängt die Verfügbarkeit von GitHub Pages vom Tarif und den Repository-Einstellungen ab. GitHub Pages ist eine Webveröffentlichung: keine personenbezogenen Schul- oder Schülerdaten hochladen.
